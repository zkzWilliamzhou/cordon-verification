# ADR-0004: no star-count promise

Date: 2026-11-11. Status: accepted.

## Decision

No README, release note or report states that Cordon will reach or has reached
105,000 GitHub stars. `docs/ADOPTION.md` describes conditions that help and
failure modes that hurt. The project does not buy stars or publish unverifiable
growth numbers.

## Reason

A star is a click by another person. Agent C's report calls a >105k outcome a
low-probability tail event. Treating it as a requirement would distort the
engineering and invite dishonest marketing.

## Consequences

Success metrics are time to first verdict, false-positive rate, adapter
conformance, and retained usage. The decision log records that the star target
was not achieved in this run.
